# Venture Total in Modern OverPower

This is Excelsior's concise rules reference for calculating Venture Total in Modern OverPower.  It also defines what the Draw Hand analysis may count.

## The calculation

At the end of a battle, a player's Venture Total is:

> The numerical damage from that player's successful hits to opposing characters during the current battle, plus or minus effects that explicitly modify Venture Total or explicitly change how it is counted.

Use this sequence:

1. Add the printed damage value of every numerical hit the player scored on opposing characters during the current battle.  Hits moved to the Astral Plane because their target was KO'd still count.
2. Do not add ordinary attack or defense bonuses.  A bonus changes how difficult an action is to block or how strong a defense is, but it does not become damage or Venture Total.
3. Add or subtract card, Character, Homebase, Aspect, or Event effects only when their text explicitly modifies Venture Total or says that something normally excluded now counts.
4. Apply any explicit exclusions or alternative counting instructions on cards in play.

The higher Venture Total wins the battle after both players pass.  If the totals are tied, the normal tied-battle Objective rules apply.

## Card-type guidance

| Card or value | Normal Venture treatment |
| --- | --- |
| Power card | Its printed numerical value counts when it successfully hits an opposing character. |
| Numerical Special | Its printed or stated attack value counts when it successfully hits, unless its text says otherwise. |
| Teamwork | The Teamwork's initial attack value can count as damage when it hits.  Follow-up Power cards contribute their own printed values; Teamwork bonuses do not. |
| Ally Universe | The Ally's attack value can count when it hits.  A numerical Special played as its follow-up contributes according to that Special's rules. |
| Basic Universe | Its bonus does not count as damage or Venture Total unless an explicit card effect creates an exception. |
| Training Universe | Its bonus follows the same rule as Basic Universe and does not normally count. |
| Other bonuses | A `+N` bonus does not count unless the governing text expressly says it counts toward Venture Total. |
| Explicit modifiers | Text such as “+3 to Venture Total,” “opponent is -3,” or “does not count toward Venture Total” is applied as written. |

### Explicit exceptions

Specific card text overrides the normal rule.  For example, **Eyes in the Dark** allows Basic and Training Universe bonuses to count toward Venture Total for that battle.  The official July 2025 clarification says this does not create Venture from a defensive use: the Universe card is counted only after a successful attack, unless another effect provides a different path.

## Excelsior Draw Hand analysis

The Draw Hand number is a potential Venture estimate, not a completed battle score.  It totals the base numerical values in the simulated hand after normal duplicate discards, assuming those numerical cards are used offensively and successfully hit.

The estimate:

- counts base numerical Power, Special, Teamwork, Ally, Aspect, and other attack values represented in catalog data;
- excludes Basic and Training Universe bonuses;
- honors a card's explicit “does not count toward Venture Total” wording when represented by the analyzer; and
- does not simulate targets, defenses, action order, cards already in play, or every conditional Venture modifier.

The actual cards and game state always control the final Venture Total.
